# Zapret Control — дистрибутив для Windows

Этот набор собирает имеющийся рабочий проект в папку с `ZapretControl.exe` через PyInstaller. Он не содержит готовый Windows EXE: сборку необходимо выполнить на Windows.

## Установка

1. Скопируйте `build_windows.bat` и `requirements_distribution.txt` в **корень текущего проекта Zapret_GUI** рядом с `main.py`, папками `Zapret_backend`, `zapret_frontend`, `Zapret_dir`.
2. Сделайте резервную копию рабочего проекта.
3. Запустите `build_windows.bat` двойным щелчком или из терминала PyCharm. Для сборки не нужны права администратора.
4. Результат: `dist/ZapretControl/ZapretControl.exe` и рядом `zapret_frontend` и `Zapret_dir`.
5. Перед переносом на другой компьютер проверьте запуск `.exe` без PyCharm. Для распространения архивируйте **всю** папку `dist/ZapretControl`.

## Почему так

В `main.py` путь определяется через `BASE = Path(__file__).resolve().parent`. Параметр `--contents-directory .` нужен, чтобы при заморозке exe с PyInstaller 6 рабочая папка данных `BASE` оставалась **рядом с exe**, а не в `_internal`. Qt `.ui` и `.qss` включены через `--add-data`. Каталог `Zapret_dir` копируется без перезаписи исходника и остаётся доступным для обновлений.

Если Windows сообщает, что файлы заблокированы или требуются администраторские права, это отдельная задача проверки разрешений/политик Windows. Сборщик не отключает UAC или защиту ОС.

## Важные ограничения

- `onedir` — это распространяемая папка, а не MSI-установщик.
- Предполагается, что `Zapret_backend` импортируется стандартным образом и что его зависимости доступны в окружении сборки.
- Папку с exe располагайте в месте, доступном для записи, поскольку F-04 загружает новые версии в `Zapret_dir`. Если разместить файлы в `Program Files`, без пересмотра архитектуры обновления могут перестать работать.
- На новой системе драйверы/компоненты самого zapret могут потребовать разрешений, предусмотренных исходным проектом. Автоматически обходить их не следует.
- Если предыдущая версия `main.py` пытается получать `latest_installation` уже в момент импорта, отсутствие `Zapret_dir` приведёт к ошибке при открытии. Держите эту папку рядом с exe.
- Обновление GUI и обновление самого zapret — независимые операции.

## Отладка

Если exe сразу закрывается, временно уберите `--windowed` из BAT-команды, пересоберите и запустите `dist/ZapretControl/ZapretControl.exe` из PowerShell: ошибки будут видны в консоли. Убедитесь, что структура каталогов рядом с exe соответствует рабочему PyCharm-проекту.
